# ImIn — نظام الحضور الجامعي الذكي 🎓📍

نظام تسجيل حضور جامعي ذكي بالتحقق الجغرافي (Geofencing) — الطالب لا يستطيع تسجيل
حضوره إلا من داخل نطاق القاعة المحدد من قبل الدكتور، مع بطاقة رقمية (QR) لكل طالب،
وسجل حضور كامل، وحظر وإنذارات للطلاب.

> By **Ahmed Shaban** — github.com/ahmedshaaban188

---

## ⚡ التشغيل السريع (الوضع التجريبي — بدون أي إعداد)

```bash
bun install   # أو: npm install
bun dev       # أو: npm run dev
```

افتح `http://localhost:3000` — النظام يعمل فوراً في **الوضع التجريبي**:
قاعدة بيانات محلية على السيرفر (`data/imin-demo.json`) مع تحديث لحظي كل 3 ثوانٍ.

## 🔐 ما الجديد في تحديث الأمان (v2)

| الإصلاح | التفاصيل |
|---------|----------|
| **كلمات المرور** | كان الدخول سابقاً بالبريد + الرقم الجامعي فقط (قابل للتخمين). الآن: كلمة مرور إلزامية تُخزَّن **هاشاً** (SHA-256 طبقتان + ملح فريد لكل مستخدم + 100 تكرار) ولا تُرسل الكلمة الأصلية لأي مكان |
| **التحقق من الدور من السيرفر** | كان بإمكان أي طالب فتح لوحة الدكتور بتعديل `role` في localStorage من DevTools. الآن يُعاد التحقق من الدور من قاعدة البيانات عند كل فتح للصفحة |
| **منع تكرار الرقم الجامعي** | لا يمكن إنشاء حسابين بنفس الرقم الجامعي/الوظيفي |
| **إخفاء الهاشات من الـ API** | استجابات تسجيل الدخول/الإنشاء لا تكشف هاش كلمة المرور أو الملح إطلاقاً |
| **توحيد حد النطاق** | الحد الأدنى لنطاق الجلسة أصبح 10م في الواجهة والسيرفر معاً |

> **للحسابات القديمة:** أي حساب أُنشئ قبل هذا التحديث (بدون كلمة مرور) لن يستطيع
> الدخول — أنشئ حساباً جديداً بنفس البريد (بعد حذف القديم من
> `data/imin-demo.json` في الوضع التجريبي).

## 🗄️ التحويل إلى Supabase الحقيقي (اختياري — دقيقتان)

1. أنشئ مشروعاً مجانياً على [supabase.com](https://supabase.com)
2. افتح **SQL Editor → New query** والصق محتوى `supabase/schema.sql` ثم **RUN**
3. من **Project Settings → API** انسخ URL و anon key
4. أنشئ ملف `.env.local` في جذر المشروع:

```bash
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
```

5. أعد تشغيل السيرفر — النظام يتحول تلقائياً للوضع الحقيقي (Realtime كامل)

> **ملاحظة أمنية للإنتاج:** سياسات RLS الحالية متساهلة (تعمل بـ anon key
> من المتصفح). للإنتاج الفعلي يُنصح بالانتقال إلى Supabase Auth مع تقييد
> السياسات بـ `auth.uid()` — خطة محفوظة للإصدار القادم.

## 🧭 الوظائف

### لوحة الدكتور
- فتح جلسة حضور: التقاط GPS تلقائي + نطاق بالأمتار (10–1000م) بمؤقت مباشر
- كشف حضور لحظي (Realtime) للطلاب داخل النطاق
- إنهاء الجلسة + تصدير الكشف CSV متوافق مع Excel العربي
- حظر طالب (فصل من المادة) / إنذارات — مع تريجر يمنع المحظور على مستوى قاعدة البيانات
- إحصائيات: حضور / غياب / إنذارات لكل طالب

### لوحة الطالب
- كشف تلقائي للجلسات المفتوحة + إشعار لحظي
- حساب المسافة بالمعادلة الكروية (Haversine) + خريطة مصغرة (SVG) توضح موقعك
- زر الحضور مقفل خارج النطاق — ومنع التكرار على مستوى قاعدة البيانات
- بطاقة رقمية (QR) + سجل حضور سابق كامل

```
    ├── password.ts           ← تجزئة كلمات المرور (Web Crypto)
    ├── geo.ts                ← Haversine + أخطاء GPS بالعربية
    └── supabaseClient.js     ← إعداد Supabase
```
