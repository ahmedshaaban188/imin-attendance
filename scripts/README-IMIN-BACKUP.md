# ImIn | نظام الحضور الجامعي الذكي — نسخة احتياطية (Backup)

> تاريخ النسخة: 2026-10-08
> هذه نسخة كاملة من كود نظام ImIn جاهزة للاسترجاع والتشغيل على أي جهاز.

---

## 1) محتويات النسخة

| المجلد / الملف | الوصف |
|---|---|
| `src/` | كل كود النظام (واجهات الطلاب والدكاترة + الدخول + طبقة البيانات + الترجمة عربي/إنجليزي) |
| `data/imin-demo.json` | قاعدة بيانات الوضع التجريبي (البيانات الفعلية: مستخدمين، جلسات، حضور، تحذيرات) |
| `supabase/schema.sql` | مخطط قاعدة البيانات الحقيقية (Supabase) — يُنفَّذ مرة واحدة عند الربط |
| `db/custom.db` | قاعدة SQLite الداخلية |
| `prisma/` | مخطط Prisma |
| `public/` | أيقونات النظام |
| `package.json` + `bun.lock` | قائمة الحزم المطلوبة |

**غير مضمنة عمداً** (تُولَّد تلقائياً): `node_modules` و `.next` و `.git`.

---

## 2) طريقة الاسترجاع والتشغيل (خطوة بخطوة)

### المتطلبات
- **Node.js 20+** (أو **Bun** — أسرع)

### الخطوات

```bash
# 1) فك الضغط عن المجلد ثم ادخل عليه
cd imin-system

# 2) ثبت الحزم (اختر واحدة)
bun install            # إذا عندك Bun
npm install            # إذا عندك Node فقط (آبطأ شوية)

# 3) شغّل النظام
bun run dev            # أو: npm run dev
# (أول تشغيل هيولّد Prisma Client تلقائياً)

# 4) افتح المتصفح
http://localhost:3000
```

### لو ظهر خطأ متعلق بقاعدة البيانات (DATABASE_URL)
افتح ملف `.env` وخلّي المسار نسبي:

```
DATABASE_URL="file:../db/custom.db"
```

## 3) وضعان للنظام

### أ) الوضع التجريبي (الافتراضي) — يشتغل فوراً بدون إعداد
- بيانات مستخدمين تجريبية + بث لحظي كل 3 ثوانٍ
- البيانات تُحفظ في `data/imin-demo.json`
- كلمة السر الافتراضية لتجارب الدخول موجودة في نفس الملف

### ب) الوضع الحقيقي (Supabase) — للإنتاج
1. أنشئ مشروعاً مجانياً على https://supabase.com
2. من **Project Settings → API** انسخ: `Project URL` و `anon public key`
3. أنشئ ملف `.env.local` في جذر المشروع وضع فيه:

```
NEXT_PUBLIC_SUPABASE_URL=رابط_مشروعك
NEXT_PUBLIC_SUPABASE_ANON_KEY=مفتاحك_العام
```

4. افتح **SQL Editor** في لوحة Supabase والصق فيه محتوى `supabase/schema.sql` ونفّذه
5. أعد تشغيل النظام — سيتحول تلقائياً للوضع الحقيقي

> الإعداد موجود وموثّق بالعربي داخل `src/lib/supabaseClient.js` (أول 20 سطر).

## 4) ملاحظات معمارية سريعة

- النظام واجهة واحدة `/` تتنقل بين 3 شاشات (دخول / لوحة دكتور / لوحة طالب) حسب الجلسة
- الجلسة محفوظة في `sessionStorage` (تُمسح بإغلاق المتصفح) + خروج تلقائي بعد خمول 120 ثانية
- الترجمة عربي/إنجليزي في `src/lib/i18n-ar.ts` و `src/lib/i18n-en.ts`
- كل استعلامات الواجهات تمر من `src/lib/data-layer.ts` (موحّد للوضعين)

## 5) نسخة الأمان

- للاحتياط الكامل انسخ مع المجلد: `data/imin-demo.json` (بيانات الوضع التجريبي)
- لو ربطت Supabase فبياناتك الحقيقية في السحابة — انسخها من لوحة Supabase عند الحاجة
